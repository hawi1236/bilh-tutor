# ብልህ ቱቶር (Bilh Tutors) - ድሬዳዋ ቅርንጫፍ Web Platform

A modern web application for **Bilh Tutors (ብልህ ቱቶር)** to connect parents, students, and tutors in Dire Dawa and across Ethiopia.

## Quick Start
The page and API must both run through the Node.js server. From this project folder, run:

```sh
npm install
npm start
```

Then open http://localhost:3000 in your browser. Do not open `index.html` directly; browser file pages cannot reach the `/api` routes.

## 🛠 Features
- Amharic interface with Google Ethiopic Typography
- Responsive dark/light theme switcher
- Tutor request form for parents/students
- Tutor application form for educators
- Interactive tutor showcase with grade level & subject filtering
- Grade 8 & 12 national exam practice quiz module
- Direct click-to-call link (`0951155327`) and Telegram link (`https://t.me/bilh_tutor`)
